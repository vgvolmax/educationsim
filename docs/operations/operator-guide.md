# EducationSim: запуск и сопровождение на Windows 11

EducationSim — учебный тренажёр по водяному тёплому полу для менеджеров по продажам. Каталог помогает читать исходные карточки и составы. Программа не рекомендует товары к покупке и не предназначена для расчёта реального монтажа.

## Первый запуск

Получите согласованный архив `EducationSim-Windows-x64.zip` и контрольную сумму через внутренний канал. Проверьте SHA-256:

```powershell
Get-FileHash -Algorithm SHA256 -LiteralPath '.\EducationSim-Windows-x64.zip'
```

Сверьте хеш с `SHA256SUMS.txt`, распакуйте архив **целиком** в новую папку и запустите `EducationSim.exe`. Не запускайте EXE из окна ZIP. Интернет для расчёта, уроков и встроенного каталога не нужен; ссылки на карточки открываются во внешнем браузере. Если штатная защита Windows запрещает запуск, передайте ИТ сообщение и хеш файла, не отключайте защиту.

## Пять минут для нового менеджера

1. Откройте «Прямое подключение: две петли». На 2D-схеме смотрите воду и управление, в «3D сцене» откройте разрез. Если 3D недоступно, продолжите в 2D.
2. В «Расчёт» подготовьте прогон и выполните один шаг. Сравните значение расхода до и после закрытия клапана. Пунктир показывает условное соединение, пока реальная трасса не задана.
3. В новом проекте установите котёл и коллектор. Выберите котёл в списке или на схеме, в «Соединение элементов» выберите «Подача», затем «Вход подачи» коллектора. Для обратной линии выберите соответствующие разъёмы. Сигнальные связи начинают с выхода. Неподходящие назначения не предлагаются; отмена выбора не меняет проект.
4. Вернитесь на старт и откройте L01. Урок — самостоятельная попытка; «Открыть свободную копию» переносит схему в отдельный проект без замены урока.

## Файлы и защита от потери работы

Проекты автоматически записываются для текущей учётной записи Windows в `%APPDATA%\EducationSim`. Если сохранение не выполнено, окно может остаться открытым: повторите запись или экспортируйте изменения. Не выбирайте «Закрыть без сохранения», если работа нужна.

Для передачи используйте «Экспорт проекта и прогонов». На другом компьютере выберите JSON в «Импорт проекта JSON», проверьте запись и нажмите «Открыть отдельную копию». Проектный JSON не является полным бэкапом профиля и каталога. Локальный выпуск справочника выбирается через «Каталог ВОЛМАКС» → «Локальное обновление» → «Архив выпусков». Ошибочный импорт не должен менять активный выпуск; не удаляйте профиль, чтобы переключить каталог.

## Обновление и откат

Сохраните проект, экспортируйте важные прогоны, штатно закройте приложение и сделайте копию всей папки профиля. Храните предыдущий ZIP с хешем и обе распакованные папки раздельно. Перед каждым переключением убедитесь, что не осталось процесса приложения:

```powershell
Get-Process -Name EducationSim -ErrorAction SilentlyContinue
```

После запуска проверьте фактический путь:

```powershell
Get-Process -Name EducationSim | Select-Object Id,Path
```

Обе сборки под одним пользователем используют один профиль. Если старое окно открыто, запуск второго EXE может лишь перевести фокус в старое окно. Совпадение номера версии также ничего не доказывает. Перед откатом сохраните копию нового профиля отдельно. На отдельном тестовом аккаунте проверьте предыдущую сборку, работу сохранённых проектов и восстановление заранее сделанной копии профиля. Не удаляйте работающий профиль ради теста и не перезаписывайте единственную резервную копию. При ошибке остановитесь: зафиксируйте хеш, путь, состояние и симптомы, передайте ИТ журнал `startup.log` без рабочих данных.
