# EducationSim: датчики, управление и источник (B06)

`compileControls` проверяет граф с одним отправителем на вход. Датчик, запрос и разрешение передаются по разным сигнальным типам; комнатный термостат читает воздух, отдельный ограничитель пола читает поверхность, RTL читает обратку. Графы запроса поддерживают И/ИЛИ, и цикл возможен только через явную задержку. В защитном пути поддержано только И, без задержки и без обхода на ручном запросе. Незавершённый защитный путь не считается исправным.

- `advanceControls` получает измерения из предыдущего снапшота с номером модельного тика. Данные из текущего тика, просроченные и отсутствующие показания не используются. Комнатная уставка не меняется при ограничении пола. Потеря показания ограничителя снимает разрешение. Защёлка снимается только по явному сбросу при свежем измерении ниже порога восстановления.
- Команда нагрева, электрическое питание, наличие горячего источника и физическое положение привода выведены отдельно. Положение движется к цели с объявленным временем полного хода. Без питания NC идёт к закрытому, NO к открытому положению; само открытие не доказывает нагрев. Отсоединённый по V12 ограничитель явно диагностируется; команда такого учебного сценария не объявляется защищённой.
- Источник вычисляет запрос, рабочую уставку по наружной температуре, право на включение и реально разрешённую мощность отдельно. Для теплового насоса проверяется минимальный прямой расход, для всех источников применяется заявленный предел подачи/мощности. Упрощённая модель не заменяет заводские кривые. Сквозной шаг симуляции и привязка к Worker остаются в B08.
