# EducationSim: расчёт трассы (A04)

- Вход: ортогональное помещение в метрах, прямоугольные запретные зоны, вход и выход, выбранный шаг и минимальный радиус трубы. Радиус поступает из учебных или подтверждённых технических данных; алгоритм не назначает изделию паспортные параметры.
- Эталон: 4×5 м, 150 мм, труба 16×2 мм с отдельно заданным радиусом. Генератор строит связную змейку или две вложенные ветви улитки с единым разворотом. Для автоматического варианта входы находятся на одной стене на расстоянии шага, задано направление первого хода. Для L-формы змейка сужает пары проходов у выреза; если запретная зона требует изолировать часть пола, она предупреждает о неполном покрытии. Сложная недоступная геометрия отклоняется, не заменяя ручную трассу.
- Длина включает прямые, дуги, явно заданные подводки и стояки. Переход по высоте допускается только в положении указанного стояка. Стыки с подводками сохраняют точку и касательную; изгиб ведётся внутри участка. В местах пересечения строительного шва возвращаются координаты гильз. `lengthM` использует аналитическую длину дуг; `measureRoute(points)` возвращает длину ломаной, например при повторном открытии сохранённых координат. Визуализация дуг по точкам приближённая (не больше 15° на хорду); результат не является монтажным проектом.
- Расчётный Worker не изменяет проект. Результат готов к предпросмотру только для актуального номера ревизии и запуска. Отмена останавливает Worker. До явного принятия результат не меняет предыдущую линию, а ручную требует подтвердить отдельно. Привязка к UI выполняется на этапе D02.
