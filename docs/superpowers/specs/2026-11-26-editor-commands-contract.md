# EducationSim: правила команд редактора (A03)

- `registry.ts` содержит начальные учебные типы и порты, без паспортов или утверждения совместимости реальных артикулов. Типы имеют стабильные ID. Гидравлические порты описывают среду, посадку и размер. Сигнальный вход принимает один совместимый по значению выход; выход разрешено разветвить. Учебная трасса может связать однотипные трубные гнёзда одного наружного размера. Внутренний диаметр проложенной трубы для расчёта хранится отдельно. Предложение переходника означает, что обе его стороны совместимы с проверяемыми типами; оно не добавляет его автоматически и не является торговой рекомендацией.
- `topology.ts` проверяет одиночное действие и диагностирует связи загруженного черновика. Код ошибки содержит путь и ID порта. Проверка полной замкнутости, циклов и инженерной состоятельности не входит в A03.
- `reducer.ts` применяет команды атомарно и возвращает один новый номер ревизии. Перед подтверждением замены `previewReplacement` перечисляет сохранённые и отсоединяемые связи и удаляемые трассы. Замена сохраняет ID и положение компонента, назначает профиль выбранного типа и отсоединяет старый снимок каталожных параметров. Команда замены требует текущий номер ревизии и выполняется отдельно от пакета редактирования. Удаление связи удаляет только её зависимые трассы. Ошибка не изменяет исходный проект.
- `history.ts` хранит до 32 состояний отмены. Undo/redo возвращает данные прошлого состояния под новым номером ревизии, чтобы будущий ответ Worker со старым номером не стал актуальным. Успешная правка после отмены удаляет ветку повтора. История текущего сеанса не является форматом хранения.
