# EducationSim: расчётные сети (B01)

`compileProject` превращает проект v1 в детерминированный граф расчёта. Данные идут из канонического реестра портов и явной внутренней схемы компонента. Коллектор объединяет подающие порты в одну гребёнку, обратные в другую, а не соединяет все порты вместе. Внешние трубы и внутренние устройства сохраняют идентификаторы. Контрольные связи и тепловые связи выделены отдельно.

- Источники и насосы обозначены независимо от труб. Подключение не является расчётом расхода. Изолированная сеть, где всё оборудование явно отключено, остаётся в графе с нулевым расходом. Выключение насоса на действующей схеме не закрывает открытый патрубок; такой контур не проходит компиляцию. Замкнутый пассивный контур без включённого насоса получает отдельное предупреждение.
- Каждому домену назначаются опорный узел и начальное манометрическое давление проекта. Это начальное условие фиксированной учебной модели, а не вычисленное давление. Стороны теплообменника остаются разными доменами. Соединение сторон в одну сеть или конфликт заданных жидкостей блокирует расчёт.
- Приоритет длины: принятая трасса петли, явно проложенная труба, оценка прямой по размещению компонентов с предупреждением. Для сохранённых трасс используется длина ломаной по координатам. Пустая/нулевая геометрия без пригодной оценки не даёт расчётного канала. Все трассы пола сохраняют связь с комнатой.
- Эффективные параметры: начальные значения модели, затем совместимый снимок каталога, затем явные параметры экземпляра. Снимок другой модели блокирует компиляцию, даже если поля совпадают. Неизвестные паспортные свойства не интерпретируются как измерения. Числовые данные не подтверждают выбор конкретного SKU.
- Вода использует учебные константы V04. Пропиленгликоль — только 30% по массе, свойства при 20 °C: 1032,1 кг/м³, 3960 Дж/(кг·К), 0,0030 Па·с. [ASHRAE 2025 SI, гл. 31, таблицы 10, 11, 13](https://handbook.ashrae.org/handbooks/F25/SI/f25_Ch31/f25_Ch31_si.aspx). Это фиксированная точка, не аппроксимация на весь диапазон температур и не допуск оборудования. Этиленгликоль и другие концентрации не рассчитываются. Интерполяция, гидравлика и тепловая динамика появятся отдельными этапами.
