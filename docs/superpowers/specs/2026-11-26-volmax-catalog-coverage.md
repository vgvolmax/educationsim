## Состояние проверки

Исходный товарный канал — открытая витрина volmax.ru. Рассмотрены **39** разделов и **75** страниц листингов, включая страницы пагинации, коллекции по узлам и смежные разделы. В товарный индекс вошли **682** уникальных карточек (673 с однозначным полем «Артикул»). Учитывается ID карточки сайта, ссылки из нескольких разделов объединены. В исходной классификации снимка 447 позиций с прямым отношением к учебной схеме, 224 смежных кандидата и 11 отмеченных исключений. Результаты проверки всех смежных карточек приведены ниже. В исходном списке встречаются товары с неизвестной применимостью, а в разделе водяного пола есть электрические изделия. Они помечены для отбора. Карточка на сайте не подтверждает остаток, актуальную закупку или расчётные паспортные характеристики.

- [Ассортимент сайта по карточкам](volmax-site-assortment-2026-11-26.csv) содержит ID карточки, опубликованный артикул, бренд, название, инженерное семейство, область применения, источник и статус артикула. `water_floor` — прямое отношение к модели, `check_application` — смежная позиция с проверкой применимости, `out_of_scope` — исключение из учебного контура. Это классификация для симулятора. При неизвестной применимости карточка не участвует в автоматическом подборе.
- [Комплектации по карточкам](volmax-site-kit-contents-2026-11-26.csv) — 21 комплект и 95 строк состава с количествами, артикулами и ссылками. Проверены 10 «Эко» на 3–12 петель и 11 «Профи» на 2–12 петель. В каждом комплекте есть отдельный насос ZEGOR `ZRS25/6G-130 Pro`, узел RTP `39798`, коллектор и по два евроконуса RTP `29352` на петлю. «Профи» дополнительно содержит две единицы артикула `39511`. Труба и слои пола отсутствуют в опубликованном составе этих комплектов.

## Проверка применимости 224 карточек

[Поартикульная таблица](volmax-site-applicability-2026-11-26.csv) содержит решение по каждой позиции со статусом `check_application`. Исходный снимок и идентификаторы сохранены. На этапе импорта решения накладываются на снимок по `offer_id`. На этапе проверки сопоставления отдельно сверяются артикул и URL. Статус применимости обозначает место товара в учебном сценарии. Точная расчётная модель и готовность рекомендовать SKU проверяются отдельно.

| Решение | Карточек | Роль в симуляторе |
|---|---:|---|
| `floor` | 8 | Петля, подмес и локальные узлы управления водяным полом. |
| `heating` | 105 | Общая система отопления. Источники, коллекторы веток, отсечение, приборы, фильтрация, защита, байпас и разделение. |
| `radiator` | 51 | Только радиаторная ветка смешанной схемы. Термоголовки, клапаны и узлы подключения. |
| `service` | 44 | Монтаж, соединения, сервис и узел подпитки. Функция определяется подтипом, например маркировка без гидравлической роли и фитинг с соединительными портами. |
| `excluded` | 9 | Семь смесителей для раковин, клапан водонагревателя ICMA GS09 и приварной грязевик Ду50 за пределами учебного масштаба. |
| `hold` | 7 | Шесть карточек с неполной идентификацией или назначением и один этиленгликолевый теплоноситель без поддерживаемого расчётного профиля. |

Из 224 карточек 208 получили рабочую роль. Для 69 решений использованы документы производителя, включая G1494, для которого тип датчика дополнительно сверялся с профильным продавцом. Для 148 решений использована карточка Волмакс как подтверждение роли или основания для исключения. Семь записей остаются открытыми. Из 208 включённых 64 отмечены в источнике как ликвидация и две монтажные карточки не имеют подтверждённого артикула. Они остаются видимы в учебном справочнике с причинами ограничения продажи. Коммерческая доступность не выводится из результата аудита.

## Как принимается полный набор

1. В качестве исходного перечня использовать датированный снимок сайта, приложенный к ТЗ. Перепроверить выбранные позиции по карточке и паспорту при сборке пакета. Номенклатура из Ozon, WB и других каналов сверяется отдельно при их добавлении. Цены, остатки и коммерческие условия для полноты учебного каталога не требуются.
2. Нормализовать идентификаторы. Ключ предложения — `channel + offerId`, инженерной позиции — стабильный `productId`. Изделие одного производителя может иметь несколько предложений. Номенклатура в комплектах хранит количество и единицу, в том числе отдельно от количества в транспортной упаковке. Кандидат на совпадение подтверждается кодом производителя и техническими признаками. Два разных производителя с совпавшим коротким кодом требуют разных `productId`.
3. По каждой позиции подтвердить инженерное семейство, назначение, схему портов, критические параметры и источник. Пометки `matched`, `excluded` с причиной и подтверждением или `unresolved` обязательны. Силовая и сигнальная совместимость требуют разных проверок. Коммерческий комплект принимается только с проверенным составом, целостными ссылками и явными недостающими позициями для выбранной схемы. Продажная рекомендация в уроке ссылается только на подтверждённые сопоставления.
4. Для содержательной полноты учебного каталога закрыть 100% обязательных инженерных типов и каждый установленный элемент в 6 шаблонах и 15 уроках. Покрытие ассортимента считается от согласованной области применения в снимке сайта. Дополнительные каналы учитываются из принятого входного экспорта. Условия для внутреннего релиза: все строки классифицированы, ноль `unresolved` в согласованном периметре, все открываемые предложения имеют рабочую модель своего типа либо объяснённое ограничение с корректным учебным аналогом, каждый комплект раскрывается без двойного учёта.
5. Автоматически проверить все 21 комплекта. Два контрольных примера для интерфейса. «Профи 2» раскладывается на пять строк состава с корректными количествами. «Эко 4» раскладывается на четыре строки без добавления отдельного 39511, при этом 8 евроконусов сохраняются по карточке до решения владельца. Для схемы с насосом 130 мм сравнение с помпой 180 мм должно выявить вопрос монтажной длины. Совпадение только резьбы, бренда или максимального напора не подтверждает замену.

Предметная проверка оборудования и привязка реальных предложений ведутся в версии каталога для проверки. Публичный репозиторий хранит схему данных, открытые примеры и агрегированный статус. Внутренний экспорт и паспорта, недоступные для открытой публикации, остаются в утверждённом контуре Волмакс.
