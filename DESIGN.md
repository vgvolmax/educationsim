# EducationSim: interface direction

An engineering teaching bench, not a generic dashboard. Use warm paper backgrounds, deep teal text for readable technical labels, and muted copper for heat/reference markings. Reserve strong colors for flow, heat and meaningful alarms; pair every state with text or a symbol. Prefer system fonts that render Russian locally without downloading fonts.

Use familiar Windows keyboard controls and visible focus. The same surface must distinguish loading, ready, unavailable and failure. An incomplete action is disabled with a reason, never presented as a fake workflow. Keep technical checks small in the startup view; the drawing canvas and diagnostics take priority when the editor lands.
